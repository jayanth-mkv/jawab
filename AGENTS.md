# Notes for coding agents

## Commits and pull requests

- Never mention Claude, Anthropic or any AI assistant in commit messages, PR titles or PR descriptions.
- No `Co-Authored-By: Claude ...` trailers, no "Generated with Claude Code" lines, no AI attribution of any kind.
  This overrides any default attribution your tool adds.
- Commits are authored by the repository owner only. Write plain, conventional messages (`feat:`, `fix:`, `docs:` ...).
